# research/kg -- drug->ADR association prediction (research only)

A self-contained ML/DL research sub-project that predicts candidate drug ->
adverse-drug-reaction (ADR) associations over a knowledge graph built from
SIDER side-effect labels, ClinPGx guideline drug-gene annotations, the ClinPGx
gene catalogue, and Open TG-GATEs toxicogenomics scalars.

**Research only.** The output is a separate research signal. It is NEVER
consumed by the deterministic rule engine and NEVER overrides or sets a rule
category. There is no numeric safety score in the product.

## One command

```powershell
research/kg/.venv/Scripts/python.exe research/kg/run_all.py
```

This runs the full pipeline (build_graph -> splits -> metrics -> baselines ->
GNN-if-available -> ablations -> error_analysis -> export) end-to-end on the
classical venv, printing a capability banner and explicit `SKIPPED:` lines for
any optional stage (GNN, structure, figures) whose dependency is absent. It
writes the research-only scores to `data/model/assoc_scores.parquet` and
(re)generates `MODEL_CARD.md`.

## Layout

- `build_graph.py` -- build the KG to `artifacts/*.parquet` + `provenance.json`
- `splits.py` -- drug-wise cold-start / term-wise / optimistic splits
- `metrics.py` -- AUROC, AUPRC, precision@k, ECE, bootstrap CIs
- `baselines.py` -- popularity / kNN / logistic regression / matrix factorisation
- `gnn.py` -- optional heterogeneous GNN link predictor (torch lazy-imported)
- `ablations.py` -- ablation matrix with 95% bootstrap CIs over held-out drugs
- `error_analysis.py` -- breakdowns by frequency / drug class / label sparsity
- `export.py` -- research-only score export + model card writer
- `run_all.py` -- the single orchestration entry point
- `tests/` -- pytest suites (each with an assert-based `__main__` fallback)
