# Rule coverage expansion: TCAs, SSRIs, warfarin multi-gene, tacrolimus, tamoxifen, PPIs, voriconazole, irinotecan, G6PD drugs

Three FEATs added 38 pharmacogenomic rules across 19 drugs, expanded the evidence table by 8 primary-guideline records, and added 47 reference test cases. FEAT-001 also fixed a pre-existing Windows path bug in `tests/helpers.js` that had blocked all test execution on this machine. All rules carry `status='verified'`, `evidenceLevel=null`, and no numeric score or probability fields. `node --test` passes 213/213 and `npm run validate-data` exits 0. Two issues remain: the `RULE_COVERAGE_ADDITIONS.md` document required by the task spec is absent from both mandatory output locations, and the voriconazole CYP2C19 PM rule cites the CPIC guideline while implementing only the weaker DPWG recommendation.

**Watch for:** (confirmed) `RULE_COVERAGE_ADDITIONS.md` missing from `docs/` and `genomex-final/rule-coverage/`; (confirmed) `R-PGX-VORICONAZOLE-CYP2C19-PM` misattributes CPIC — the cited annotation recommends an alternative agent for adult PM patients, not a dose reduction.

**Verdict**: NEEDS_CHANGES

## High-level view

The Windows path fix (`fileURLToPath` in `tests/helpers.js`) is confirmed in place and tests run cleanly on this machine. The fix was correctly extended to `scripts/validate-data.mjs` as well.

All 38 new rules pass schema validation, carry `evidenceLevel=null`, and have no numeric score or probability field. Every cited G:PA annotation ID exists in `data/guidelines/index.json` (the `G:` prefix is a rule-layer convention; the index stores bare `PA*` IDs). All cited `E-*` IDs exist in `data/evidence.json`. Actions of `avoid` and `modify` come exclusively from `status='verified'` rules with cited G:PA evidence.

The primaquine-deficient rule deviates intentionally from the FEAT spec: the spec said to cite both `G:PA166279621` and `G:PA166119846`, but the index confirms `PA166119846` covers only dapsone, methylene blue, pegloticase, rasburicase, tafenoquine, and toluidine blue — primaquine is not in its drug list. Citing only `G:PA166279621` is correct.

Three rule families carry explicit `TODO` gaps in `limitations[]` — omeprazole/lansoprazole PM/IM and UGT1A1 intermediate metabolizer — acknowledged in the FEAT spec and acceptable as documented scope boundaries.

The `R-PGX-VORICONAZOLE-CYP2C19-PM` rule is a confirmed attribution error. It cites `G:PA166161537` (the CPIC voriconazole annotation) alongside `G:PA166104990` (DPWG), but the encoded action and rationale only implement DPWG's 50% dose reduction. The CPIC annotation's guideline summary explicitly recommends selecting an alternative agent for adult PM patients — the same recommendation encoded for UM patients. A reviewer or downstream user examining the evidence citations would assume the rule reflects the CPIC recommendation; it does not.

The `RULE_COVERAGE_ADDITIONS.md` document is absent from both `docs/` and `genomex-final/rule-coverage/`. The `genomex-final/rule-coverage/` directory exists but is empty. The task spec and context both require this file at both locations.

### Voriconazole PM attribution gap

The CPIC voriconazole annotation (PA166161537) summary: "recommends selecting an alternative agent that is not dependent on CYP2C19 metabolism in adults who are CYP2C19 ultrarapid metabolizers, rapid metabolizers **or poor metabolizers**."

`R-PGX-VORICONAZOLE-CYP2C19-PM` cites this annotation (`G:PA166161537`, `E-CPIC-VORI-2017`) but encodes `action='modify'` with rationale "DPWG recommends that CYP2C19 poor metabolizers receive 50% of the standard dose." The UM rule (`R-PGX-VORICONAZOLE-CYP2C19-UM`) correctly encodes alternative-agent as the primary action. For PM adults, CPIC recommends the same approach, not a dose reduction. Citing the CPIC annotation without implementing its recommendation creates a false implication that CPIC endorses dose reduction for PM.

Fix options: (a) update the PM rule's action, headline, rationale, and `alternatives` to reflect CPIC's alternative-agent recommendation and note DPWG's dose-reduction alternative; or (b) remove `G:PA166161537` and `E-CPIC-VORI-2017` from the PM rule's evidence and cite only DPWG.

### Clomipramine CYP2C19 UM encoded as modify, not avoid

DPWG (PA166184528) recommends avoiding clomipramine for CYP2C19 UM in OCD/depression indications. The rule encodes `action='modify'` because the engine cannot distinguish OCD from other indications from current inputs. The limitation is documented in the rule: "DPWG recommends avoidance specifically for OCD/depression indications; the indication cannot be confirmed from available inputs so this is encoded as modify, not avoid." This is a deliberate conservative trade-off — callers who need the stronger recommendation for OCD must consult the cited guideline.

### Missing/unknown genotype handling

The `ami-2d6-nm` reference case was adjusted from the spec: it provides both `CYP2D6='normal'` and `CYP2C19='normal'`. The spec-as-written provided only `CYP2D6='normal'`, which correctly produces `needs_info` because amitriptyline has rules for both genes and the untested CYP2C19 genotype is not treated as normal. The fix is correct.
