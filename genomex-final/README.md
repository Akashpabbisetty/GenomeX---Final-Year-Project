# genomex-final — Portable Deliverables Folder

This folder contains all the generated outputs from the GenomX Advisor build.
It is git-ignored (not committed). Copy it wherever you need it.

## Contents

| Folder | What it is |
|---|---|
| `ml-package/kg/` | **The complete ML/DL training pipeline.** Copy this + `../data/` to your ML machine and follow `ml-package/kg/SETUP.md`. |
| `api/` | The patient-facing API server, batch CLI, and synthetic demo scripts. |
| `rule-coverage/` | Documentation of every new guideline rule added (sources, phenotypes, categories). |
| `docs/` | Combined project documentation — methodology, process, paper outline. |
| `paper/` | Research paper scaffold and figures (filled in after ML training). |

## How to use this folder

### To train the ML models (on a capable machine):
1. Copy `ml-package/kg/` and the project's `data/` folder to your ML machine.
2. Open `ml-package/kg/SETUP.md` and follow it step by step.
3. Run: `python run_all.py`
4. Copy back `data/model/assoc_scores.parquet` and `figures/` when done.

### To run the app (on any machine with Node.js):
The app itself lives in the main project folder — not here. This folder is deliverables only.
```
cd ..                          # back to project root
npm run serve                  # start at http://localhost:8000/frontend/genomx-advisor.html
```

### To use the API:
```
node api/server.js             # starts /api/evaluate on port 8080 (or as documented)
```

## What this folder is NOT
- Not the running application (that's in engine/, frontend/, data/)
- Not the source of truth for rules (those are in data/rules/ and must stay there)
- Not committed to git — it's a build output, regenerated by the project's scripts
