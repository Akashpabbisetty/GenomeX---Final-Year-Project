# Tech
- Engine & UI: plain ES modules (Node 22 / browser), no framework, no innerHTML (use `frontend/ui/dom.js` `h()`), strict CSP, no inline styles/handlers.
- Tests: `node --test "tests/*.test.js"`; UI tests use jsdom. Every new rule needs a reference case citing its source in `tests/fixtures/reference_cases.js`.
- Data: versioned JSON in `data/`; ingestion is Python (`scripts/ingest/*.py`), must be idempotent and record hashes/licences in `data/sources.json`. Validate with `npm run validate-data`.
- ML (research): Python 3.12, PyTorch + PyG, scikit-learn, DuckDB/Parquet for large data; seeds fixed; drug-wise (cold-start) splits; report CIs.
- Large data stays out of git (`data_raw/`); derived artefacts are regenerated by scripts.
